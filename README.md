# OneCart

OneCart is a full-stack e-commerce web application built using the MERN stack. Currently, the project is in active development with core user authentication and project structure set up.

## Current Progress
- User registration and login using JWT and HTTP-only cookies
- Google Sign-In integration using Firebase Authentication
- Separate folder structure for Frontend, Backend, and Admin panel

## Planned Features
- AI-based product search and recommendations
- Product listing, cart, and wishlist functionality
- Payment integration (Razorpay)
- Admin dashboard for managing products and orders

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, React Router, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Auth:** Firebase Authentication, JWT, bcrypt

## Running Locally

1. Clone the repository:
   ```bash
   git clone [https://github.com/yatindrakumaryunish-del/OneCart.git](https://github.com/yatindrakumaryunish-del/OneCart.git)
   cd OneCart
2. Setup and run Frontend:
   cd frontend
   npm install
   npm run dev

3. Setup and run Backend:
   cd Backend
   npm install
   npm run dev
